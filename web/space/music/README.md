# 點歌機歌單

`tracks.json` 是點歌機的歌單。每次打開點歌機都會重讀一次，所以加歌、下架都不用重開頁面。

## 加歌

1. 把音檔（mp3／m4a／ogg／wav）放進這個資料夾。
2. 在 `tracks.json` 的 `tracks` 裡加一行：

```json
{ "id": "rainy_day", "file": "rainy_day.mp3", "title": "雨天", "en": "Rainy day", "color": "#4fb4ff", "bpm": 80 }
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 是 | 英數、底線、連字號，最多 40 字。待播與「上次放到哪首」都記這個，改了就當成另一首歌 |
| `file` | 是 | 這個資料夾裡的檔名，不能有路徑 |
| `title` / `en` | | 中文／英文歌名，沒寫就顯示 id |
| `color` | | `#rrggbb`，點歌機的燈和唱片標籤用這個顏色 |
| `bpm` | | 寫了的話，換歌會等下一拍才淡出，點歌機的燈也會跟著拍子亮 |
| `loopSamples`, `rate` | | 無縫循環曲才要填：一圈的取樣數和取樣率（預設 44100）。檔案要做成「一整圈＋開頭 1 秒」。沒填就放到尾巴換下一首 |
| `gain` | | 這首的音量倍數（0～2，預設 1），用來把各首調到差不多大聲 |

格式不對的那一行會被略過，不會讓整份歌單壞掉。

## 下架

把那一行從 `tracks.json` 拿掉就好（檔案可以留著，也可以刪掉）。待播裡的這首會被拿掉；正在放的那首會放完這一輪才換。

## 載不到的歌

檔案不見、或格式解不開的歌，在點歌機上會標成「放不出來」，輪到它的時候跳過。重新整理頁面後會再試一次。
